Markov Chains Clearly Explained! Part - 1

Markov Chains Explained

Markov chains model systems where future states depend only on the current state. They appear in statistics, biology, economics, physics, and machine learning. This video uses a restaurant example to explain the core concepts.

  • A restaurant serves hamburgers, pizza, or hot dogs daily. Each day's food depends only on the previous day's choice. Example: 60% chance of pizza tomorrow if today is hamburger.
  • Transitions are shown as weighted arrows between states. Self-pointing arrows represent staying in the same state. Example: 20% chance of hamburgers tomorrow if today is hamburger.
  • All outgoing arrows from a state must sum to 1.0, as they represent probabilities.

Markov Property

The key Markov property states that future states depend only on the current state, not past history. This simplifies modeling complex systems.

  • Example: If restaurant served pizza (day 1), hamburger (day 2), pizza (day 3), probability of hot dogs on day 4 is 0.7. This depends only on day 3, not earlier days.
  • Mathematically: P(X_{n+1} = x | X_n = x_n, ..., X_1 = x_1) = P(X_{n+1} = x | X_n = x_n). This property makes real-world problem-solving more efficient.

Stationary Distribution

Over many steps, probabilities converge to a stationary distribution. This represents long-term state probabilities that remain constant over time.

  • Simulated 100,000 steps: Hamburger 35%, Pizza 21%, Hot Dog 46%. Matches linear algebra solution.
  • Stationary distribution is found by solving πA = π where A is the transition matrix. π must sum to 1.0 as it's a probability distribution.
  • This method confirms convergence and identifies unique stationary states. More than one stationary state would require multiple eigenvectors with eigenvalue 1.
